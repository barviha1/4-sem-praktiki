# PWA Заметки с напоминаниями и уведомлениями

Комплексное веб-приложение для управления заметками и задачами, реализованное в рамках практических занятий №13–17 по дисциплине «Фронтенд и бэкенд разработка».

## О проекте

Это прогрессивное веб-приложение (PWA) позволяет:
- Создавать, просматривать и хранить заметки в `localStorage`
- Работать в офлайн-режиме благодаря Service Worker
- Устанавливаться на устройство как нативное приложение (Web App Manifest)
- Загружать интерфейс по стратегии App Shell (мгновенный каркас)
- Получать push-уведомления о новых задачах и напоминаниях
- Устанавливать напоминания с возможностью отложить на 5 минут
- Обмениваться событиями в реальном времени через WebSocket (Socket.IO)

## Технологии

- **Frontend**: HTML5, CSS (Chota), JavaScript (ES6+)
- **PWA**: Service Worker, Web App Manifest, App Shell
- **Real-time**: Socket.IO (клиент и сервер)
- **Push-уведомления**: Web Push API, VAPID
- **Backend**: Node.js, Express, web-push, body-parser, cors
- **Безопасность**: HTTPS (mkcert для локальной разработки)

## Практическая работа №13 - Service Worker

- Регистрация Service Worker
- Кэширование статических ресурсов при install
- Перехват fetch-запросов с ответом из кэша или сети
- Работоспособность офлайн (загрузка страницы и заметок)

## Практическая работа №14 – Web App Manifest

- Создан manifest.json (name, short_name, start_url, display, theme_color, icons и др.)
- Подготовлены иконки разных размеров (PNG)
- Подключён manifest в index.html
- Добавлены мета-теги для iOS и Android
- Service Worker кэширует иконки и манифест
- Проверена установка приложения на компьютер/устройство

## Практическая работа №15 – HTTPS + App Shell

- Настроен локальный HTTPS через mkcert
- Реализована архитектура App Shell (каркас + динамический контент)
- Два кэша: статический (Cache First) и динамический (Network First)
- Страница "О приложении" загружается динамически и доступна офлайн

## Практическая работа №16 – WebSocket + Push

- Реализован Node.js сервер с Socket.IO
- Клиент подключается к WebSocket и отправляет событие newTask
- При добавлении задачи событие рассылается всем клиентам (всплывающее сообщение)
- Реализована подписка на push-уведомления через PushManager
- Кнопки "Включить уведомления" / "Отключить уведомления"
- Сервер отправляет push-уведомления всем подписанным клиентам
